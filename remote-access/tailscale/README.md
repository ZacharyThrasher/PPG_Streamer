# Tailscale setup (host side)

Friends join through Tailscale **node sharing**: your PC is shared into their own free Tailscale account. They can see that one machine and nothing else of yours, and you can revoke access any time.

## How it works

```
Friend's Jellyfin player --(WireGuard, encrypted)--> your PC: tailscale serve (HTTPS :443) --> Jellyfin 127.0.0.1:8096
```

- `tailscale serve` terminates HTTPS with a real certificate for `https://<pc>.<tailnet>.ts.net`, so friends get a clean URL and no certificate warnings.
- It is tailnet-only. It is not Funnel, so the public internet cannot reach it.
- Windows Firewall needs no new rules because Tailscale forwards to Jellyfin on the loopback address.
- The video normally flows directly between the two computers. If a direct path cannot be made, Tailscale falls back to a relay, which works but is slower. `check-access.ps1` shows which one each friend is on.

## Steps

### 1. Run the script (once)

Admin PowerShell, from the repo root:

```powershell
powershell -ExecutionPolicy Bypass -File remote-access\tailscale\setup-host.ps1
```

It installs Tailscale (winget), signs you in, checks Jellyfin, sets up `tailscale serve`, and prints the URL for friends. It is safe to re-run. `-Undo` removes the serve rule.

If it stops at the serve step, enable HTTPS once: https://login.tailscale.com/admin/dns -> turn on MagicDNS -> **Enable HTTPS**. Then re-run.

### 2. Admin console tweaks (cannot be scripted)

At https://login.tailscale.com/admin/machines:

1. Menu on your PC -> **Disable key expiry** (otherwise the PC falls off your tailnet after about 180 days).
2. Menu on your PC -> **Share** -> create an invite link. Make one per friend, single use.
3. Revoke later from the same Share dialog (**Revoke invite**).

### 3. Jellyfin users

Dashboard -> Users -> add one user per friend. Give each a unique password, and keep your own admin account for admin only (not for watching).

Optional but recommended: Dashboard -> Playback -> Streaming -> set the **Internet streaming bitrate limit** to around your upload speed divided by the number of friends (for example 40 Mbps upload and 4 friends -> 8 to 10 Mbps).

### 4. Send the friend kit

[../FRIEND-GUIDE.md](../FRIEND-GUIDE.md) covers the Tailscale steps for friends. The full invite message is generated by `friends/New-FriendAccount.ps1`.

## Limits and gotchas

| Item | Detail |
|---|---|
| Friends need their own Tailscale account | Node sharing needs the recipient to own a tailnet. Signing in with Google/Microsoft/Apple/GitHub creates one automatically. |
| Name must be fully qualified | Shared machines resolve only by `<hostname>.<tailnet-name>.ts.net`, not the short name (Tailscale docs). The script prints the right one. |
| Invite links | Single-use by default, expire after 30 days (Tailscale docs). |
| Plan limits | Tailscale docs list sharing as available on all plans. Whether shared friends count against the Personal plan user cap is not confirmed; check the admin console if you share with many people. |
| TVs and consoles | Need a Tailscale app on the device. Not every box has one. Friends can use a laptop or phone instead. |
| Phones | One VPN at a time on most phones. |
| Upload speed | Still the real ceiling. Tailscale does not add bandwidth. Test with 2 friends before relying on 4. |

## Fallback if HTTPS gets in the way

Friends can use the plain address instead: `http://<pc-tailscale-ip>:8096` (the 100.x.y.z address shown in the Tailscale app). This is still encrypted by Tailscale. It needs Jellyfin's Windows Firewall rule to allow the Tailscale network, and some browser features that require HTTPS may be unavailable.
